# Visual direction: the Photoshop-era enthusiast web, engineered with modern CSS

The site deliberately avoids both the generic modern developer portfolio (SaaS hero, gradients, bento grids, glassmorphism, floating tech logos) and the generic "retro pixel portfolio". The reference is the Photoshop/Illustrator-designed personal, portal and anime/fansite web of about 2003–2009: layered mastheads, textured interface chrome, custom graphical elements, dense but intentional portal layouts, badges and editorial pages. It is rebuilt with responsive layout, semantic HTML, WCAG 2.2 AA, high-DPI assets and strict performance budgets. Pixel/8-bit elements are accents only. The Timeline ("Archive") and Kanji ("Dictionary") areas have related identities within the same design system, and may override only tokens and a small set of decorative components.

## Consequences

- Future contributors may be tempted to "modernize" the look. That would reverse this decision and needs a superseding ADR.
- Style tiles for the three identities must be approved by Charles before the component library is built. Typefaces are chosen through those tiles.
