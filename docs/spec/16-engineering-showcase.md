**Framework judgement (ADR-0001):** the site is not built with Angular, even though Angular is Charles's strongest framework. The colophon explains why, because choosing the right tool for a content site is itself a senior-level decision. Individual interactive demos or case-study artefacts MAY use Angular, React or other technologies where they are appropriate. Each demo lives under `/lab/**` with its own ADR, its own PERF-06 row and a no-JS description (ADR-0016). A demo MAY require JS when the interaction is the product, and it never adds runtime to information pages.
